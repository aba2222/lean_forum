# Contributing to Lean Forum

Thanks for your interest in contributing to Lean Forum. Contributions of all kinds are welcome, including bug fixes, new features, documentation improvements, tests, and other improvements.

## Getting Started

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test your changes before submitting them.
5. Submit a pull request with a clear description of the change.

Please keep contributions focused and avoid including unrelated changes in the same pull request.

## Commit Guidelines

Each commit should represent **one logical change**.

* Keep commits small and focused.
* Do not combine unrelated changes in a single commit.
* No **"and" commits**. If a commit message describes two unrelated changes, split them into separate commits.

Use the following commit message format:

```text
<area>: <imperative summary>
```

Examples:

```text
forum: add post search
```

Use an imperative summary: describe what the commit does, such as `add`, `fix`, `update`, `remove`, or `refactor`.

## Code Quality

Before submitting a contribution:

* Follow the existing code style and project structure.
* Keep changes as simple and maintainable as possible.
* Add or update tests when appropriate.
* Make sure your changes do not introduce unnecessary dependencies or unrelated modifications.

## Pull Requests

A pull request should have a clear purpose and remain focused on a single logical change whenever possible.

Please include:

* A clear description of what changed.
* The reason for the change.
* Any relevant testing information.
* Screenshots or examples when applicable.

Avoid mixing refactoring, formatting changes, bug fixes, and new features in the same pull request unless they are directly required for the same logical change.

## AI-Assisted Contributions

AI-assisted contributions are welcome, but contributors remain fully responsible for the code they submit.

**A human must be in the loop at all times.**

Contributors must review, understand, test, and take responsibility for any AI-generated or AI-assisted code, documentation, or other content before submitting it.

**The assistance must be disclosed.**

If AI tools were used in preparing a contribution, clearly disclose their use in the pull request description. The disclosure should briefly describe how AI assistance was used.

AI assistance does not replace code review, testing, or the contributor's responsibility for the submitted changes.
